# CodeAlpha Flashcard Quiz

A simple and interactive Flashcard Quiz App developed as part of my CodeAlpha Data Science Internship.

## Features

- Show and hide answers
- Next and Previous flashcards
- Add new flashcards
- Edit existing flashcards
- Delete flashcards
- Clean and responsive user interface

## Technologies Used

- HTML
- CSS
- JavaScript
